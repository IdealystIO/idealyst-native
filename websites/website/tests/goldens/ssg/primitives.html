Primitives
PrimitivesThe fixed, minimal set of things the framework knows how to put on screen. Everything else — every component, every screen, idea-ui itself — composes out of these. Each cell below is the real primitive rendering live on this backend.
ContainersThe structural primitives. Everything else nests inside one of these.
viewA flex box. The structural workhorse — no behavior of its own.
scroll_viewA view that scrolls its overflowing content.

ContentPrimitives that render media — text runs, bitmaps, and vector icons.
textA run of text. Reactive when its child reads a signal.The quick brown fox jumps over the lazy dog.
styled_textOne text node with inline-styled ranges — per-run font, color, and background — realized as attributed text on every backend.Inline runs like code_chips live inside one text node, so the whole paragraph wraps as a unit.
imageA bitmap from a URL (here, an inline SVG data URI).
iconA vector icon — inline SVG on web, CAShapeLayer on iOS, VectorDrawable on Android.
InputsControlled primitives — the host owns the value as a signal; the input round-trips through on_change.
buttonA labeled tappable with native button semantics.
0 clicks
text_inputA text field whose value is owned by the parent.
toggleA switch bound to a Signal<bool>.
sliderA numeric slider with min/max bounds and a step.
FeedbackPrimitives whose only job is to show that something is happening.
activity_indicatorAn indeterminate loading spinner. No value — it just spins.
NavigationDeclarative navigation — a link dispatches against the closest ambient navigator (and emits a real <a href> on web).
linkWraps a child that navigates when pressed.Go to Core concepts →
ListsThe virtualized-list entry point — only the visible rows are realized. Backends drive their native virtualization widget.
flat_listA virtualized list. Pass data, a stable key, an item size, and a row renderer.
Floating & transitionsSubtrees that escape the parent's layout and clipping (modals, popovers) plus animated mount/unmount. The host owns the open/close signal.
overlayA viewport-anchored portal — centered, with a dismissible backdrop. Use for modals.
anchored_overlayA portal that tracks a trigger element — popovers, dropdowns, tooltips.
presenceMounts and unmounts with enter/exit animations — the exit plays before the node leaves.
Control flowReactive structure. You write a plain `if` (or `match`, or `for`) inside ui!, and the macro lowers it to the `when` primitive — the old branch's scope drops and the new one builds fresh when the signal changes.
whenReactive if/else. Toggling the signal swaps the branch.
Branch: OFF
GPUThe escape hatch into raw rendering. The framework hands you a native GPU surface (a wgpu device) and stays out of the way — you own every pixel.
graphicsA GPU canvas. on_ready gives you a wgpu surface; the framework never interprets what you draw.See it running on the home page →
